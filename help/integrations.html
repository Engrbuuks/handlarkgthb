API tokens

Settings, Integrations, API tokens (members: your account, API tokens): name it, choose a workspace token (owner) or a personal token, and tick what it may do. It is shown once. Read the API guide.

Webhooks and chat alerts

Webhooks send signed events to any https address. Chat alerts post to a Slack, Microsoft Teams or Discord channel through an incoming webhook you make in that app. Private tasks never leave, hidden people show as A teammate, leave says when but never why, and quiet hours apply.

Each one sends only what the person who added it may see: a manager's webhook gets the time, attendance and leave of the people they look after, and invoice events only with Invoices and client billing. The owner sees who added each one. When that person can no longer manage integrations it is switched off at once, and when they leave, or the API token that made it is revoked, it stops too. Switching it back on makes it yours. Only the person who added it, or the owner, can make a new signing secret.

Send again in the delivery log repeats a delivery only to the same address, for the same person, while they may still see what it is about: when a webhook changes hands or address, its earlier deliveries can no longer be sent again.

Every send connects to the address that was checked a moment before, so a web address cannot be pointed at a private network in between.
