The browser extension

Your timer in Chrome, Edge and Firefox: start, stop and add tasks from the toolbar and from GitHub, Jira, Trello, Asana, Google Docs and Gmail.

On this page

  3. Using it
  4. Start timer on other sites
  5. Privacy and Proof mode

The Handlark extension puts your timer one click away. It uses your own token, sees only your own tasks and time, and never captures your screen.

Install it

Install Handlark: timer and tasks from the Firefox Add ons site or Microsoft Edge Add ons, or from the Chrome Web Store when it is listed there. Until then, your administrator can load it unpacked from the Handlark folder (see extension/README.md).

Connect it

  1. In Handlark, open your account (owners: Settings, This device) and choose Browser extension, then Show a code.
  2. In the extension, open its settings and type the 10 character code. It works once, for 10 minutes.
  3. Pin the extension to the toolbar.

Before it is used, the extension shows the workspace and the name the code belongs to. Choose Yes, connect only if both are yours; if someone sent you the code, choose Cancel. Until you choose, the connection does nothing, and if you close the settings without choosing it is cancelled after 10 minutes. Type the code only into the extension in your own browser, and never read it to anyone. You see each connected browser in Handlark with its computer, such as Chrome on Windows, and can disconnect it there at any time.

Instead of a code you can paste a personal API token, but only one with just tasks, time and clients ticked; a token that can do more is refused.

Using it

  • Toolbar: pick a client and a task and start the timer; the badge shows how long it has run. Stop it with an optional line on what you did.
  • New task: add a task for today and start it in one go.
  • Today: your tasks due today, overdue or in progress.
  • Still working: the badge shows a question mark and you can answer from the popup.

Start timer on other sites

In the extension settings, turn on the sites you use: GitHub issues and pull requests, Jira, Trello, Asana, Google Docs, Sheets and Slides, and Gmail. The browser asks you for each site. A small Start timer button then appears on an issue, card, task, document or email; pressing it finds the Handlark task linked to that page, or makes one with the page's title and link, and starts your timer.

Privacy and Proof mode

Nothing is read from a page until you press its button. Your token is kept encrypted in the browser, where the pages the extension adds buttons to cannot read it. The extension never captures your screen, never reads your history or other tabs, and has no analytics. For a client with Proof mode on, it opens the task in Handlark instead, where you share your screen with consent. The optional idle hint uses only whether the computer is in use, and asks you, privately, what to do with time away.
